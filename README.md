# Eagle

## ▶ [Watch the 1-minute demo video](https://www.loom.com/share/ba5ba86becc542c68314095f9fb2ce0b)

**https://www.loom.com/share/ba5ba86becc542c68314095f9fb2ce0b**

---

**Flying should be as easy as getting in a car.** Say where you want to go, and Eagle does the whole VFR
pre-flight preparation and hands you a GO / NO-GO briefing. You stay pilot in command.

- **Plan:** route, weather, NOTAMs, fuel, mass & balance, risk and logistics, in one go
- **Fly:** a cloud agent watches your flight over a 160-character satellite link

Built on **Gemini 4 Argon** at the Gemini 4 Argon SF Hackathon.
